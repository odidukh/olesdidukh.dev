Etappi is a modern, offline-first task manager built on a shared React Native codebase that runs on web, mobile, and desktop. Web is in production, mobile is in beta with an App Store launch in flight, and desktop runs on Tauri 2 with a signed updater.

## One UI runtime, four targets

The hard architectural bet is that all clients render the same React Native primitives:

- **Web** — Next.js 15 + React Native Web (17 routes, themes, keyboard shortcuts, command palette)
- **Mobile** — Expo 54 + Expo Router 6 (Phase 3 redesign live: Inbox, Today, Upcoming, Search, Projects)
- **Desktop** — Tauri 2 with signed auto-updater and hardened capabilities
- **Shared UI** — `packages/ui` family-primitive system with bold / glass / native variants

This is what makes "ship one product on four platforms" tractable for a solo build.

## Backend

A Hono + tRPC API on Vercel Serverless, split into 15 domain routers. Persistence is Neon Postgres with Drizzle ORM, schema split across 14 domain files plus a relations file.

| Concern  | Choice                        |
| -------- | ----------------------------- |
| API      | Hono + tRPC 11                |
| Database | Neon Postgres + Drizzle ORM   |
| Auth     | Clerk                         |
| Payments | Stripe                        |
| Storage  | Cloudflare R2 (S3-compatible) |
| Push     | Web Push (VAPID) + Expo       |
| Sync     | PowerSync (SQLite ↔ Postgres) |
| Testing  | Vitest + Playwright           |

## Sync model

Of 21 tables, 14 are replicated to mobile SQLite via PowerSync (`users`, `projects`, `sections`, `tasks`, `labels`, `comments`, `project_members`, `activity_log`, `attachments`, `notifications`, `filters`, `reminders`, `task_dependencies`, `focus_sessions`). 7 stay server-only and never touch a client (`push_subscriptions`, `admin_audit_log`, `stripe_webhook_events`, `moderation_reports`, `user_blocks`, `entitlements`, `entitlement_events`).

All tables use UUID keys, ISO 8601 timestamps, and fractional indexing for user-controlled ordering.
