A comprehensive personal productivity platform for managing activities, tracking habits, optimizing energy levels, and building better routines. The system spans a Next.js 16 PWA on the web and an Expo / React Native app on mobile, both backed by the same Postgres database and a shared TypeScript core that holds all non-trivial business logic.

## Architecture

A Turborepo monorepo with three first-class workspaces:

- `apps/web` — Next.js 16 PWA with React Query, NextAuth.js, and CSS Modules
- `apps/mobile` — Expo 54 / React Native 0.81 app with Expo Router 6, NativeWind 4, and SQLite-backed offline cache
- `packages/shared` — types, validation, contracts, scheduling, habits, recurrence, energy modeling, and i18n; the single source of truth for both clients

Persistence is Prisma 7 against PostgreSQL (Supabase), with 317 API endpoints exposing the domain to both clients.

## Why a shared package

Productivity logic — recurrence rules, habit streak calculation, energy/load modeling, scheduling windows — is the kind of code where divergence between platforms quickly turns into bugs the user can feel. Centralizing it in `packages/shared` means every fix and every new rule lands once and ships everywhere.
